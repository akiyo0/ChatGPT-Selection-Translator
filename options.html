ChatGPT Selection Translator - Settings

Create one on the API Keys page at platform.openai.com. Billed by usage - separate from a ChatGPT subscription.

Defaults to gpt-4o-mini. You can change it to any other Chat Completions-compatible model name.

Used for "quick translate" via the keyboard shortcut or toolbar button, without picking a language each time.

    After selecting text and right-clicking, the "ChatGPT Translate" submenu lists these languages - click one to translate into it.

    Want to customize the shortcut? Open chrome://extensions/shortcuts
